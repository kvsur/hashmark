# 独立发布交接要求

日期：2026-08-31

用户希望未来即使没有 Codex 辅助，也能独立完成 Hashmark 的升级、构建、TestFlight 分发和后续迭代。

因此本计划新增以下长期交付要求：

- 在仓库维护可独立执行的 `docs/App-Store-Release-Runbook.md`。
- 每个 Apple 后台步骤记录入口、固定字段、判断标准和常见阻塞。
- 明确版本号与构建号的递增规则，以及每次迭代必须重复的验证。
- 保留可审计证据，但不把 Apple 账户个人资料、证书私钥、API Key 或测试者邮箱写入仓库。
- 本轮后续发现的新流程和失败恢复方法，应在完成对应步骤时同步补充进手册。
