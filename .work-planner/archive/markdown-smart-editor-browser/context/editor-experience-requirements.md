# 编辑体验优化：用户原始需求与方向确认

## 原始需求（2026-08-10）

> 1. editor 中通过 ai 快捷按钮选中内容弹出 的AI Modal 中，选中的内容是 raw，而不是 preview，这一点可以优化；
> 2. 大优化任务：editor 纯手动编辑的时候，现在很原始；反正我自己作为app开发者都觉得不好用；没有像在 vscode，notion，语雀等市面主流支持 md的编辑器好用；我举一个最简单的例子，我输入 `1. one item;` 换行的时候并没有 自动 加上 `2. `, 还有很多这样的待优化交互点；需要你帮助我探索优化最佳实践，且在一个 iOS/iPad app中好用；
>
> 1可以即时做，但是 2 需要好好规划；

## 方向确认（2026-08-10）

建议方向：保留可见 Markdown 源码与 Preview/Edit 双模式，建设“源码优先的智能编辑器”，不改造成 Notion 式所见即所得块编辑器。
