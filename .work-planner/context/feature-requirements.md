# AI 输入附件 — 原始需求（用户口述，2026-07-17）

> 当前 App 在使用 AI 辅助生成功能的时候，仅仅支持输入文字，但是实际让 AI 生成内容的时候，
> 可能会想要添加一下自己的上下文：图片、现有的文档 供模型参考；
>
> ChatGPT 和 Claude API 都支持上传附件。
>
> App 要支持在输入的时候支持这两个功能：选择照片（仅图片），引用当前现有的文档；
> 合适 UI/UX；合适附件处理逻辑（异常）。

## 澄清后锁定的范围（本次会话）

- **图片**：仅相册选择（PhotosPicker），**不做拍照**。拍照留 TODO 注释、后续版本迭代。
- **引用文档**：从 App 内现有文档库（FileStore/DocumentNode）挑已有 .md。**引用外部文件**（PDF/txt 等经系统文件选择器）留 TODO 注释、后续版本迭代。
- **启用范围**：仅**生成类动作**——续写（continueWriting）+ 自由创作（custom，含首页「生成整篇」与编辑器内自定义）。润色/整理不加附件入口。
- **图片处理**：自动压缩降采样到 provider 安全尺寸 + 限制张数（默认 4 张）；模型不支持视觉等 API 报错时给可读提示，不把原始错误体直接抛给用户。
- **引用文档**：可多选、整篇正文注入 user 消息；超大文档给软提示（假设，可纠正）。
