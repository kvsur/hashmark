# 多语言 i18n 原始需求（用户原文，逐字保存）

来源：2026-07-15 用户发起 /phased-work-planner 时的需求描述。原文照录，未改写。

---

当前app 预留了多语言切换入口，暂未实现，UI 多语言 i18n 也没有翻译；app计划支持的语言：中文、英文、中文繁体、日德语、韩语、德语、俄罗斯语；

优先匹配用户切换存储的多语言；没有就适配系统语言；系统语言在当前不支持时 兜底英文；

多语言需要特殊处理的地方：agent prompt，上面提到的几种语言对应几种prompt；
系统提示 system prompt 增强：在system prompt 注入当前用户的 国家代码和语言代码；

## 澄清记录（bootstrap 访谈，2026-07-15）

原文中「日德语」经确认为「日语」的笔误（德语在原文中已单列）。最终语言清单 7 种。

三个澄清问题与用户的选择：

1. **语言清单** → 「7 种：简中/英/繁中/日/韩/德/俄」
   即 zh-Hans、en、zh-Hant、ja、ko、de、ru。

2. **AI 生成内容用哪种语言** → 「跟随文档/用户输入语言（推荐）」
   保持现有 outputContract 语义：UI 是德语但文档是中文时，续写仍出中文。
   UI 语言只决定 prompt 本身用哪种语言写，不强制输出语言。

3. **7 套 agent prompt 怎么组织** → 「英文骨架 + 语言指令（推荐）」
   prompt 主体用英文写一份（模型对英文指令遵循度最好、token 更省），
   末尾按 locale 注入语言指令。只维护 1 份，加语言零成本。
   代价：现有中文 prompt 打磨过的语感需要重写成英文。
