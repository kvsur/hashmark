# S2a 隐私政策七语言与路由验收

日期：2026-08-30

## 需求确认

Hashmark 已支持简体中文、英文、繁体中文、日文、韩文、德文和俄文。隐私政策仅提供中英文虽不必然构成审核问题，但与 App 的语言体验不一致，因此将公开政策同步扩展至七种语言。

语言选择规则：

1. App 打开隐私政策时，通过 `?lang=` 显式传递 App 当前生效语言。
2. 网页存在受支持的 `lang` 参数时，以参数为准。
3. 网页没有有效参数时，匹配浏览器或系统的首选受支持语言。
4. 无法匹配时回退到英文。

页面使用原生下拉选择器切换语言，切换后同步更新 URL、HTML `lang`、页面标题与可见政策正文。旧的 `#english` 和 `#chinese` 链接继续兼容。

## 支持语言

| 语言 | URL 值 |
|---|---|
| English | `en` |
| 简体中文 | `zh-Hans` |
| 繁體中文 | `zh-Hant` |
| 日本語 | `ja` |
| 한국어 | `ko` |
| Deutsch | `de` |
| Русский | `ru` |

## 验证结果

- 七种显式 `lang` 路由、页面标题、选择器状态和唯一可见正文：PASS
- 下拉切换后 URL 与正文同步更新：PASS
- 无参数与不支持参数的系统首选语言匹配：PASS
- App 隐私链接传递当前生效语言：PASS
- 1280 px 桌面布局、390 px 移动布局与深色模式：PASS
- Debug 模拟器构建与 RegressionAudit：PASS
- 测试中发现并修复显式 `lang=en` 被系统语言覆盖的问题：PASS
- 测试中发现并修复德文长标题在 390 px 宽度溢出的问题：PASS

面向正式公开发行前，七种法律文本仍建议由对应语言的母语法律审阅者复核措辞。
